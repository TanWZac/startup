# Student Accommodation Website (Flask)

A maintainable, modular Flask website inspired by Iglu, UniLodge, and Scape. Responsive, accessible, and ready for integration.

## Features
- Modular Flask structure (Blueprints)
- REST API for integration
- Responsive design (Bootstrap)
- Accessibility and ISO web standards
- Easy to extend and maintain

## Setup

1. Install dependencies:
	```bash
	pip install -r requirements.txt
	```
2. Run the app:
	```bash
	python run.py
	```
3. Visit [http://localhost:5000](http://localhost:5000)

## Structure
- `app/` - Main application code
  - `main.py` - Main routes
  - `api/` - API endpoints
  - `templates/` - HTML templates
  - `static/` - Static files (CSS, JS, images)
- `run.py` - App entry point
- `requirements.txt` - Python dependencies

## Accessibility & Standards
- Uses semantic HTML and ARIA roles
- Responsive for all devices
- Cross-browser compatible
- Ready for further ISO/ADA compliance
